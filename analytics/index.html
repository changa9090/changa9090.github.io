집계 범위와 한계 / Scope & limitations

  • 자체 집계는 쿠키·로컬/세션 저장소·기기 지문·방문자 ID를 사용하지 않습니다. 이벤트마다 임시 무작위 UUID만 사용하며 최대 2회 재시도합니다.
    No cookies, local/session storage, fingerprint or visitor ID for this telemetry. A random per-event UUID exists only in memory; at most two retries. 서버 이벤트 ID는 디스크에 저장하지 않습니다. RAM 중복 확인의 논리적 유효 기간은 24시간이며 만료 항목은 다음 유효 수신 또는 재시작 때 제거됩니다. 재시작하면 중복 확인 기록이 초기화됩니다. 100,000개 한도에서는 기존 ID를 제거하지 않고 공간이 생길 때까지 HTTP 429를 반환합니다. Server event IDs are never persisted. RAM deduplication uses a 24-hour logical retry window; expired keys are removed on the next valid ingestion or restart, not by a timed purge. Restart clears deduplication. At 100,000 IDs, the server returns HTTP 429 until space becomes available; it does not evict IDs.
  • 문서가 처음 보일 때 1회 조회를 집계합니다. 새로고침은 새 조회이며 BFCache 복원은 추가 집계하지 않습니다.
    One view per visible document load. Reloads count; BFCache restoration does not. Hidden prefetches are not counted until shown.
  • 입력값·검색어·양식 내용·전체 유입 URL을 전송하지 않습니다. 유입 경로는 기기에서 고정 범주로 변환합니다.
    No form inputs, search terms or raw referrer/query strings. Locally classified per-page source buckets, not original session acquisition, can be inaccurate or spoofed.
  • 봇 판정은 휴리스틱입니다. 광고 차단·JavaScript 비활성화·네트워크 오류로 특히 GitHub 조회가 누락될 수 있습니다. 위조 요청도 완전히 배제할 수 없습니다.
    Heuristic filtering is not proof of humanity. Blocking, disabled JavaScript and network errors may undercount GitHub; spoofed traffic cannot be fully excluded.
  • 기존 페이지의 역사적 방문 카운터는 별도이며 저장소를 사용할 수 있습니다. 자체 집계와 비교하거나 합산해 고유 방문자로 해석하지 마세요.
    Legacy historical counters remain on their original pages, unchanged and separate. They may use storage and different counting rules. This is not a site-wide “no cookies” claim.
  • Google Analytics는 실제 허용 선택 후에만 로드됩니다. 각 페이지의 방문 분석 설정에서 철회할 수 있습니다. 이 통계 화면 자체는 비콘을 전송하지 않습니다.
    Google Analytics loads only after opt-in. Withdraw using Analytics settings on each page. This dashboard sends no telemetry.
