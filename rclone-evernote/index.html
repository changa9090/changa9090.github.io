PERSONAL-USE GOOGLE DRIVE INTEGRATION

rclone-evernote

This page describes Evernote 217 Desktop, a personal-use desktop OAuth client within the rclone-evernote Google Cloud project, operated by Chang Min Park.

What the application does

The client connects a private note-management application to its owner's Google Drive account. It is intended to synchronize application-managed notes and attachments to a separate managed Drive folder. Authentication has been connected; full synchronization and migration acceptance are still in progress.

The application requests https://www.googleapis.com/auth/drive.file: access to specific files used with or created by this app, rather than blanket access to all Drive files. The application also checks its allowed managed folder before writes. Existing source material is not authorized for modification by this integration.

Private application, public information only

This is not a public note service and this website is not a login portal. Publishing these information pages does not expose the private application, notes, attachments, credentials or server endpoints. No Google sign-in or file upload is available here.
