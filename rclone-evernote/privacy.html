EVERNOTE 217 DESKTOP

Privacy policy

This policy describes the Evernote 217 Desktop personal-use integration in the rclone-evernote Google Cloud project. The operator is Chang Min Park (changa@gmail.com). It covers this integration and these two public information pages, not other OAuth clients in the project or other sites.

Google data accessed and purpose

With the account owner's consent, the integration uses the drive.file scope to access files created by or specifically used with this app. This may include note text, attachments and file metadata needed for synchronization. The account email address is used to verify the connected account. OAuth access and refresh tokens are used to authenticate Drive requests.

The intended purpose is private note storage and synchronization. Full migration and synchronization validation are not yet complete. Existing source files are not authorized for modification; writes are intended for a separately verified managed folder.

Storage and access

OAuth credentials are stored in owner-readable files on the operator-controlled private server. Local notes, attachments and synchronization records remain in operator-controlled storage; synchronized copies reside in the connected Google Drive account. The public website does not receive these files or tokens. This is not a public multi-user service.

Use and sharing

Google data is used to provide this private integration, not sold or used for advertising. This integration does not send Google user data to third-party AI services or use it to train general-purpose AI models. Data is transmitted to Google as needed for OAuth and Drive operations. The operator can access and administer the private system. Google processes data according to its own policies.

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Credentials are retained while the connection is needed, until revoked or removed. Notes, metadata and any configured backups are retained under the account owner's control; no fixed automatic deletion period is promised. To remove local records or retained backups, contact the operator. Revoking Google access stops future authorized API access but does not itself delete existing local or Drive copies.

Revoke access

The account owner can review or revoke the app's access in Google Account third-party connections. Revocation may affect other clients grouped under the same rclone-evernote application. Contact the operator for client-specific disconnection and removal of stored credentials.

This public website

These two static pages contain no analytics scripts, tracking cookies, sign-in form or upload form. They are hosted on GitHub Pages. The hosting provider may process normal request information such as IP addresses according to its own privacy practices; see GitHub's privacy statement. Other pages on the hosting domain have their own behavior and are outside this notice.

Changes and questions

Material changes will be reflected in the date on this page. Privacy questions and deletion requests can be sent to changa@gmail.com.
